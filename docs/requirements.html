Requirements

Only Herdr is required. Each other program adds a feature; when one is missing, the mods name it and give the install command.

macOS is the only OS the author uses; Linux and Windows code paths are implemented and covered by fake-platform unit tests but not run in the live app.

ProgramAddsInstall
Herdr desktop appRuns both mods (required).herdr.dev
ripgrep (rg)Search in the panel.macOS brew install ripgrep, Linux apt install ripgrep, Windows winget install BurntSushi.ripgrep.MSVC
Node.js 22.4 or newerMath, Mermaid and Excalidraw, with the next two.macOS brew install node, Linux nodejs.org or your package manager, Windows winget install OpenJS.NodeJS
Chrome, Chromium, Edge or BraveDraws those pictures, headless.Any one; Edge is built into Windows.
Obsidian desktop appIts own Mermaid and MathJax.Its installer; an AppImage needs the asar setting.
PopplerEvery PDF page (the first 30); without it macOS shows page 1.macOS brew install poppler, Linux apt install poppler-utils, Windows scoop install poppler
curlWeb images in notes.Built into macOS and Windows 10 or newer; Linux apt install curl
System file openerOpens other files, links and PDFs in your viewer.Built in (open, rundll32 url.dll,FileProtocolHandler); Linux xdg-open from xdg-utils

Programs are found on your PATH or in the usual install folders; for one elsewhere, see Configuration.

Vaults must live inside your home folder. Herdr mods cannot read anywhere else.
