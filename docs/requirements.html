Requirements

Only Herdr is required. Everything else is optional and adds a feature. When a program is missing, the panel or the reader says which one in plain words instead of failing.

These programs are not bundled. For each one the mods try the bare name on your PATH, then the usual install folders of your operating system (Homebrew, Snap, Linuxbrew, Nix, Volta, Scoop, WinGet, Chocolatey, Program Files), then, for Node, the folders of nvm, fnm and asdf, and last your login shell (command -v) on macOS and Linux or where on Windows. A program that was missing is looked for again after 30 seconds, so installing it while Herdr runs works. The only thing the mods ever download is a web image that a note shows (see privacy).

Where Obsidian keeps its vault list

On first run, and when you choose Import from Obsidian, the panel reads Obsidian’s own list of vaults, so you do not have to add them again. The first file in the order below that holds at least one vault is used. If none is found, the empty panel says Obsidian’s vault list wasn’t found and names the places it looked.

SystemFile read
macOS~/Library/Application Support/obsidian/obsidian.json
Linux~/.config/obsidian/obsidian.json; for Flatpak ~/.var/app/md.obsidian.Obsidian/config/obsidian/obsidian.json; for Snap ~/snap/obsidian/current/.config/obsidian/obsidian.json
Windows~/AppData/Roaming/obsidian/obsidian.json (that is %APPDATA%\obsidian)
Vaults must live inside your home folder. Herdr mods can only read files under the home folder. A vault on another drive or a network share cannot be shown; the panel lists it as outside the home folder and not readable.

Pointing the mods at a program

If the browser or Obsidian is installed somewhere unusual, set one of these environment variables before starting Herdr. They are read by the render script, first in the search order.

  • HERDR_VAULT_BROWSER, then CHROME_PATH: the full path of the browser program.
  • HERDR_VAULT_ASAR: the full path of Obsidian’s obsidian.asar.

For the other programs, put their folder on the PATH that your login shell sets, or install them in one of the usual places.
