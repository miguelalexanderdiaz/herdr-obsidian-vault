Requirements

Only Herdr is required. Everything else is optional and adds a feature. When a program is missing, the panel or the reader says which one in plain words instead of failing.

These programs are not bundled. The mods find them on your PATH, then in the usual install folders of your operating system. The only thing the mods ever download is a web image that a note shows (see privacy).

Where Obsidian keeps its vault list

On first run the panel reads Obsidian’s own list of vaults, so you do not have to add them again.

SystemFile read
macOS~/Library/Application Support/obsidian/obsidian.json
Linux~/.config/obsidian/obsidian.json; for Flatpak ~/.var/app/md.obsidian.Obsidian/config/obsidian/obsidian.json; for Snap ~/snap/obsidian/current/.config/obsidian/obsidian.json
Windows~/AppData/Roaming/obsidian/obsidian.json (that is %APPDATA%\obsidian)
Vaults must live inside your home folder. Herdr mods can only read files under the home folder. A vault on another drive or a network share cannot be shown; the panel lists it as outside the home folder and not readable.

Pointing the mods at a program

If a program is installed somewhere unusual, set one of these environment variables before starting Herdr:

  • HERDR_VAULT_BROWSER or CHROME_PATH: the browser program.
  • HERDR_VAULT_ASAR: the full path of Obsidian’s obsidian.asar.
