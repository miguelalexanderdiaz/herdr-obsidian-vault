How it works

Two mods, one cache. The panel finds a note, the reader draws it, and a small script draws what the reader cannot draw natively.

Files

FileJob
mods/vault/main.jsThe panel: vault list, tree, search box, picker menu, add vault.
mods/vault/search.js, search-core.jsSearch with ripgrep: the Herdr glue, and the pure logic (arguments, parsing, ranking, snippet) that Node tests.
obsidian-config.js, tree.js, watch.jsPure helpers of the panel: Obsidian’s vault list, the tree rules, the restartable folder watcher with its timer fallback.
mods/vault-reader/main.jsThe reader window: loading, drawing blocks, links, Keep menu, keys.
platform.js, mod-name.js (both mods)Everything that differs between operating systems (tool lookup, openers, install hints, stamps, image sizes) and the mod folder name. Pure; each mod holds its own copy because a mod folder is self-contained.
parse.js, doc.js, canvas.jsPure functions: note text to blocks; a file to a document, two embed levels deep; canvas JSON to cards and an edge picture. They do not import Herdr, so Node can test them.
assets.js, assets-core.jsEverything that becomes a picture: images, PDF pages, web images, rendered jobs; the cache. The core holds the logic without Herdr imports.
render/render.mjs, lib.mjs, page.js, excalidraw.jsThe render script and the page it loads in the headless browser. Plain Node and browser code, not Herdr mod code.

From a click to a picture

  1. A click in the panel opens the reader as a floating window with { vault, file } and records vault.open in shared state.
  2. The reader lists the vault once (to resolve wikilinks), reads the note, and parse.js turns it into blocks. Plain text blocks go straight to Herdr’s markdown view.
  3. The reader collects what needs a picture: images, PDFs, math, Mermaid, drawings, canvas edges. Each one gets a cache key made from its source, file stamp (modification time and size), your theme colours and the render version.
  4. Cached pictures show at once. Missing ones are made: images are copied into the cache (Herdr only loads pictures from its own folder) and measured; PDF pages come from Poppler; math, Mermaid and drawings are batched to the render script.
  5. The render script serves one page on 127.0.0.1, starts the headless browser with its own temporary profile, draws each job with Obsidian’s copies of Mermaid and MathJax or the project’s own drawing renderer, takes a screenshot of each result and writes a PNG plus a size file.
  6. Pictures appear as they are ready. A failure becomes a short message in place of that block, and a missing program becomes one line above the note; neither replaces the document, and neither is cached.
  7. A folder watcher redraws the note when it, or a file it depends on, changes.

If a mod name is taken

Herdr’s install rule is to never overwrite a mod, so if you already have a mod called vault, rename the new one. The folder name is spelled in one place per mod, mod-name.js (MOD, and READER in the panel); change it and the folder name together, and the mod name in your layout and keys. The shared keys keep their names unless you also want to separate the two copies. AGENTS.md in the repository lists each step.
