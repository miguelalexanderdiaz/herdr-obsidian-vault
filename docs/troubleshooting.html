Troubleshooting

Each entry gives the message as it appears, why, and what to do. The messages are quoted from the code, and the docs check script verifies that they still exist there.

If a mod breaks right after you edit it, Herdr keeps the last good version and writes the reason to <name>.error. herdr-app status shows errors too. If a layout or key makes the window unusable, press Ctrl+Alt+Shift+Esc: it sets the layout and keys.json aside.

The install hint after a message depends on your system. The requirements table lists them all.

Panel

The panel says No vault yet

Obsidian has not been run on this machine, or its list is somewhere the mod does not look. If the panel also says Obsidian's vault list wasn't found, it names the places it looked (file per system). Click Add vault and pick the folder that holds .obsidian.

Notification Not an Obsidian vault

The folder you picked has no .obsidian inside. Pick the vault’s own folder. A new vault needs to be opened in Obsidian once so it creates that folder.

Notification Vault outside your home folder

The body reads Herdr mods can only read inside your home folder, then the vault name and can't be added. A link to it from inside your home folder may work. You tried Add vault on a folder outside your home folder. It is not added to the list; it is shown dimmed as Outside your home folder. A symbolic link or a copy inside your home folder may work; that is untested. A vault that is already in the list but lies outside the home folder shows This vault is outside your home folder, which Herdr mods can't read in place of its tree.

This vault's folder is gone

The folder was moved or deleted, or sits on a drive that is not connected. Remove it from the picker (the x) and add it again.

Outside your home folder: Herdr can't read it

Obsidian knows this vault, but Herdr mods can only read inside the home folder. Move the vault under your home folder (or link it there) and add it again.

ripgrep (rg) isn't installed

Shown in the search results area instead of results. Install ripgrep with the command that follows the message, then search again. A program that was missing is looked for again after 30 seconds, so there is no need to restart Herdr. If it is installed and still not found, put its folder on the PATH that your login shell sets, or install it in a common location.

Live updates are off for this folder

On Linux, Herdr refuses to watch a tree with more than 4096 folders that git does not ignore (herdr.d.ts: “4096 non-ignored directories”). The panel then re-lists the vault every 10 seconds, and the reader checks the files of the open note every 10 seconds. Nothing is lost; changes just appear a little later.

Also on Linux, Herdr does not watch folders that git ignores at all, so a vault that is a git repository gets no live refresh for changes inside its ignored folders, and no message says so. On macOS and Windows ignored folders are watched too. Search is not affected: it looks into ignored files as well.

more not listed (search finds them)

The line reads +N more not listed (search finds them). The tree lists the first 2000 entries of a folder. Use the search box to reach the others.

rows are drawn (close a folder, or search)

The whole line reads Only the first 3000 rows are drawn (close a folder, or search). The panel draws at most 3000 rows over all open folders together, because every row is an element and a very long list makes the panel slow. Close a folder you do not need, or use the search box.

is a program, not a document.

A notice titled Not opened. The panel and the reader never launch files that start programs (.exe, .bat, .sh, .app and similar). Open the file yourself if you trust it. In the reader the same rule shows as is a program: the reader doesn't launch programs from notes.

Reader

Problems that depend on your machine appear once as a line above the note. The note and the source of each diagram or formula stay visible. They are never cached, so fixing the cause is enough.

Diagrams and math need Node.js 22.4 or newer

Also seen as Node.js 22.4 or newer isn't installed, followed by Diagrams and math are shown as source until then. Install Node.js 22.4 or newer (node --version tells you what you have). The render script uses the built-in WebSocket, and this project checks for 22.4 or newer before it starts the script.

Diagrams and math need a browser to draw them

Followed by A Chromium-based browser wasn't found and an install hint. Install Chrome, Chromium, Brave or Edge, or name the one you have: add "browser" (an absolute path) to data/vault/settings.json, or set HERDR_VAULT_BROWSER (or CHROME_PATH) in the environment Herdr was started with. If you named a browser in the settings file and it does not exist, the line says The browser named in settings.json ("browser") wasn't found, and neither was any other. before the hint. The places that are searched, in order, are on the requirements page.

Diagrams and math use Obsidian's own Mermaid and MathJax, read from the installed app

Followed by The Obsidian app wasn't found. Install the Obsidian app, or name its obsidian.asar: add "asar" (an absolute path) to data/vault/settings.json, or set HERDR_VAULT_ASAR in the environment Herdr was started with. An AppImage cannot be found by itself, so name its file. If you named a file in the settings and it does not exist, the line says The Obsidian file named in settings.json ("asar") wasn't found, and neither was an installed app. Obsidian is needed only for this; notes, canvases and images open without it.

Drawing took too long and was stopped

Open the note again to retry. Also possible: Mermaid and MathJax did not load in time; wait a moment and open the note again. The first run extracts the two libraries from Obsidian, which takes a few seconds.

Couldn't draw this

The renderer failed for another reason; the first line of its message follows, with paths replaced by <path>. A single diagram that Mermaid rejects shows Mermaid: and the reason, with its source below. A formula that MathJax rejects shows Math:. Check the syntax in Obsidian.

Poppler (pdftoppm, pdfinfo) isn't installed

All pages of a PDF need Poppler. On Linux and Windows the message ends with Until then PDFs open in your default app.; on macOS page 1 is drawn by Quick Look with no message. A PDF with more than 30 pages shows the first 30 and a row open all of it in your viewer.

isn't in the vault or No file … in the vault

The note embeds or links a file that is not in this vault (a typo, a file outside the vault, or a file that was renamed). This file is no longer in the vault means the open note itself was deleted or moved.

is larger than 1 MiB, so the reader can't open it. Open it in Obsidian.

The whole message names the kind: This note, This canvas or This drawing is larger than 1 MiB, so the reader can't open it. Open it in Obsidian. Herdr lets a mod read a text file of up to 1 MiB, so a larger one cannot be shown. Open it in Obsidian or an editor, or split it. What Herdr’s readTextFile does beyond 1 MiB is not documented (it may return nothing or reject); the reader treats a file that exists but gave nothing, or an error naming the limit, as too large. That has not been checked in the live app.

No heading or block

The link asks for a heading or a block id (^id) that the note does not have. The reader shows the whole note instead.

This canvas is empty

The canvas file has no cards. If you expected cards, check that the file is a valid JSON Canvas (Not a canvas file is shown when it is not).

Embedded too deep to show here

Embeds of embeds are followed two levels deep. Open the embedded note itself with its title link.

A web image does not show

The picture slot says why:

  • Images from the web are turned off: press Web images: off in the reader bar to turn them on.
  • curl isn't installed: install curl (it ships with macOS and recent Windows).
  • Couldn't download the image: followed by curl’s last error line. Check the address in a browser. A failed download is not saved, and is tried again after 5 minutes or when you reopen the note.
  • The address isn't a picture: the address answered with something that is not an image.
  • This image is too large to show here: larger than 40 MB (web images stop at 20 MB).
  • Not a web address this reader will fetch: only http and https addresses are downloaded.
  • Not an image this reader can show: the file is damaged or is not a supported image.
  • Not drawn (see the note above): this diagram is waiting on the problem named in the line above the note.

A picture looks old

Diagrams and formulas are cached per theme and per render version, so a new theme draws new ones. If a picture is wrong for another reason, delete data/vault/cache in the Herdr home.

Clicking a link does nothing

Only http, https and mailto links are opened, and other schemes are dropped without a message. Other files open with the system opener (open, xdg-open, rundll32); a missing opener fails silently, so check that it exists.

Still stuck

Run the short install check on the sample vault first; it tells you which step fails. Then open an issue in the repository (the “Platform report” form has the same fields) with: your operating system, node --version, the output of herdr-app check on both mods, and the exact text of the message. Do not paste note content or paths that name you.
