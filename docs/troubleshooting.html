Troubleshooting

Each entry gives the message as it appears, why, and what to do. Messages are quoted from the code.

If a mod breaks right after you edit it, Herdr keeps the last good version and writes the reason to <name>.error. herdr-app status shows errors too. If a layout or key makes the window unusable, press Ctrl+Alt+Shift+Esc: it sets the layout and keys.json aside.

Panel

The panel says No vault yet

Obsidian has not been run on this machine, or its list is somewhere the mod does not look (see the file per system). Click Add vault and pick the folder that holds .obsidian.

Notification Not an Obsidian vault

The folder you picked has no .obsidian inside. Pick the vault’s own folder. A new vault needs to be opened in Obsidian once so it creates that folder.

This vault's folder is gone

The folder was moved or deleted, or sits on a drive that is not connected. Remove it from the picker (the x) and add it again.

My vault is not in the list or cannot be opened

Herdr mods can only read inside the home folder. Keep the vault under your home folder (or link it there).

ripgrep (rg) isn't installed

Install ripgrep with the command shown for your system (also in the requirements table), then search again. If it is installed and still not found, Herdr’s PATH may not include its folder: start Herdr from a shell that has it, or install it in a common location.

The tree stops updating on a big vault

On Linux, Herdr refuses to watch a tree with more than 4096 non-ignored folders. The tree then updates when you switch vaults or reopen the panel. Folders listed in a .gitignore are not watched on Linux either.

Reader

Diagrams, formulas or drawings show their source and a notice

One of three things is missing: Node.js 22 or newer, a Chromium-family browser, or the Obsidian application (the source of Mermaid and MathJax). The notice names which one. Install it from the requirements table, or point the mod at it with an environment variable. Then reopen the note.

The messages begin with Mermaid: or Math: followed by the reason.

A PDF shows only one page, or an install hint

All pages need Poppler (pdftoppm and pdfinfo). macOS falls back to Quick Look for page 1. A PDF with more than 30 pages shows the first 30 and a row to open the whole file in your viewer.

isn't in the vault or No file … in the vault

The note embeds or links a file that is not in this vault (a typo, a file outside the vault, or a file that was renamed).

No heading or block

The link asks for a heading or a block id (^id) that the note does not have. The reader shows the whole note instead.

This canvas is empty

The canvas file has no cards. If you expected cards, check that the file is a valid JSON Canvas.

A picture looks old

Diagrams and formulas are cached per theme, so a new theme draws new ones. If the picture is wrong for another reason, delete data/vault/cache in the Herdr home.

A web image does not load

It is downloaded with curl. Check that curl exists, that the address works in a browser, and that remoteImages is not false. A failed download is not cached, so reopen the note to try again.

Clicking a link does nothing

Only http, https and mailto links are opened. Other files open with the system opener (open, xdg-open, cmd /c start); check that it exists.

Still stuck

Open an issue in the repository with: your operating system, node --version, the output of herdr-app check on both mods, and the exact text of the message. Do not paste note content or paths that name you.
