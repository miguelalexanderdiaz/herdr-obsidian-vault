Install

macOS / Linux

curl -fsSL https://raw.githubusercontent.com/miguelalexanderdiaz/herdr-obsidian-vault/main/install/install.sh | sh

Windows (PowerShell)

irm https://raw.githubusercontent.com/miguelalexanderdiaz/herdr-obsidian-vault/main/install/install.ps1 | iex

It shows what the mods reach and asks before writing anything, backs up anything it replaces, copies both mods (vault and vault-reader), adds one key to keys.json and checks each mod. Running it again updates.

Then Ctrl+Shift+M opens the Vault panel as a 420 by 640 popup in any layout; Usage says how to dock it.

Remove it: the same command with the uninstall flag. It removes what it added and leaves data/vault (cache and settings); your vaults are never touched.

curl -fsSL https://raw.githubusercontent.com/miguelalexanderdiaz/herdr-obsidian-vault/main/install/install.sh | sh -s -- --uninstall
$env:HERDR_UNINSTALL = 1; irm https://raw.githubusercontent.com/miguelalexanderdiaz/herdr-obsidian-vault/main/install/install.ps1 | iex
With an agent

Paste this into an agent running in Herdr, with the repository address filled in:

Install the Herdr mods from https://github.com/<owner>/herdr-obsidian-vault .
It has two mods, mods/vault and mods/vault-reader, and a keys.json.
Read every file first, tell me what they run and fetch, copy both
folders into my mods folder without overwriting anything, merge
keys.json after asking me about clashes, run herdr-app check on both
mods, then add the Vault panel to my layout.

The agent reads everything and tells you what the mods reach before it adds them; these run programs and download web images, as listed on Privacy. The steps an agent follows are on For agents.

By hand
  1. Clone or download the repository.
  2. Copy mods/vault and mods/vault-reader into the mods folder of your Herdr home. The last line of herdr-app --help names it: ~/.config/herdr-app unless HERDR_APP_HOME is set (on Windows, not yet checked). 
    # macOS and Linux
HERDR_HOME="${HERDR_APP_HOME:-$HOME/.config/herdr-app}"
cp -R mods/vault mods/vault-reader "$HERDR_HOME/mods/"

# Windows PowerShell
$HERDR_HOME = if ($env:HERDR_APP_HOME) { $env:HERDR_APP_HOME } else { "$HOME\.config\herdr-app" }
Copy-Item -Recurse mods\vault, mods\vault-reader "$HERDR_HOME\mods"
  3. Add the key from the repository’s keys.json to your own, keeping any key you already use (Configuration).
  4. Check both mods; both must pass. Herdr reloads mods on its own, so there is no restart. 
    herdr-app check "$HERDR_HOME/mods/vault"
herdr-app check "$HERDR_HOME/mods/vault-reader"

To remove them by hand, delete the two folders and the key, and any vault block in your layout. data/vault in the Herdr home holds the cache, the Mermaid and MathJax copies, the browser profile and the settings; delete it too if you like.

Options, name clashes and checks
  • No questions: sh -s -- --yes after the pipe (Windows: $env:HERDR_YES = 1; first).
  • Another Herdr home: HERDR_APP_HOME, or from a clone --home <folder> (-Home on Windows).
  • From a clone: install/install.sh or .\install\install.ps1.
  • Backups: under community/herdr-obsidian-vault/ in the Herdr home.
  • Keys: it asks before it replaces a key you use. Merging needs Node, or on macOS the system’s own JavaScript; without either it prints the key to add by hand.
  • Name clashes: the installer replaces a vault or vault-reader folder that is already there, after a backup. Both names are needed as they are, because the panel opens the reader by name. By hand, never overwrite another mod of the same name: rename the new one (If a mod name is taken).
  • Checks: it runs herdr-app check on each mod and says which one failed. To check what you see, follow Check your install on the sample vault.
  • Requirements: only Herdr; each optional program adds a feature (Requirements).
