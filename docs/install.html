Install

Both mods are needed. The panel opens notes in the reader, and the reader is opened by the panel. Install them under exactly the names vault and vault-reader.

Option 1: ask a Herdr agent

Herdr agents know how to install shared mods. Paste this into an agent running in Herdr, with the repository address filled in:

Install the Herdr mods from https://github.com/<owner>/herdr-obsidian-vault .
It has two mods, mods/vault and mods/vault-reader, and a keys.json.
Read every file first, tell me what they run and fetch, copy both
folders into my mods folder without overwriting anything, merge
keys.json after asking me about clashes, run herdr-app check on both
mods, then add the Vault panel to my layout.

The agent follows Herdr’s own rule: it reads everything and tells you before adding a mod that reaches the network or runs programs. This one does both, so expect that message. The list is on the privacy page.

Option 2: copy the folders yourself

  1. Get the repository: git clone https://github.com/<owner>/herdr-obsidian-vault.git (or download the zip).
  2. Find your Herdr home folder. herdr-app --help ends with a line Home: ~/.config/herdr-app (HERDR_APP_HOME picks another). Here ~ is your user folder, and the default is .config/herdr-app inside it unless the variable HERDR_APP_HOME is set. That default is quoted from Herdr’s help and has not been checked on Windows. Below, $HERDR_HOME stands for that folder.
  3. Copy mods/vault and mods/vault-reader into the mods folder inside that home. Do not overwrite a mod of the same name; if you already have one, rename the new folder and read the rename note. 
    # macOS and Linux (HERDR_HOME defaults to ~/.config/herdr-app)
HERDR_HOME="${HERDR_APP_HOME:-$HOME/.config/herdr-app}"
cp -R mods/vault mods/vault-reader "$HERDR_HOME/mods/"

# Windows PowerShell
$HERDR_HOME = if ($env:HERDR_APP_HOME) { $env:HERDR_APP_HOME } else { "$HOME\.config\herdr-app" }
Copy-Item -Recurse mods\vault, mods\vault-reader "$HERDR_HOME\mods"
  4. Merge the key from keys.json in the repository into your own keys.json (add its section and key; keep any key you already use). It is optional; see Configuration.
  5. Check both mods: 
    herdr-app check "$HERDR_HOME/mods/vault"
herdr-app check "$HERDR_HOME/mods/vault-reader"
    Both must pass. Herdr reloads mods as soon as their files change, so there is no restart.

Optional programs

Only Herdr is required. These commands install the rest in one go; skip any of them and you only lose that feature (see Requirements).

# macOS (Homebrew)
brew install ripgrep node poppler

# Linux (Debian and Ubuntu names; use your package manager’s)
sudo apt install ripgrep poppler-utils curl

# Windows
winget install BurntSushi.ripgrep.MSVC OpenJS.NodeJS
scoop install poppler

Diagrams and math also need a Chromium-family browser and the Obsidian app; the requirements page says where they are looked for.

Show the panel

The mods have "place": "none", so nothing appears until you put the panel somewhere. Pick one:

  • In a layout. Add a block to a column or stack of your layout file in layouts/: 
    { "id": "vault", "type": "block", "content": { "mod": "vault" } }
    For the herdr-portrait-layout layout, append that object to the children of the node whose id is panel-body. Its bar then shows a Vault button by itself.
  • Split a pane. Run the Herdr app command pane.split with a direction and mod set to vault (herdr-app commands lists its arguments).
  • As a popup. The repository’s keys.json binds Ctrl+Shift+M to mod.open:vault, which opens the panel as a 420 by 640 popup and, pressed again, closes it. Merge that key (see Configuration) and no layout change is needed.

First run

The panel starts with the vaults that Obsidian already lists on this machine, most recently opened first. If Obsidian has never been run, or the vault lives outside your home folder, use Add vault and pick a folder that contains .obsidian. To try the mod without a vault of your own, add examples/sample-vault from the repository, then follow Check your install.

Uninstall

  1. Remove the vault block from your layout and any keys you merged.
  2. Delete the folders mods/vault and mods/vault-reader from your Herdr home.
  3. Optional: delete data/vault in the Herdr home. It holds the picture cache, the Mermaid and MathJax copies, the headless browser profile and the reader settings. Nothing else is written outside the mod folders.

Your vaults are never touched. Herdr keeps a few values in its own shared.json (in the Herdr home) after the mods are gone: vault.list and vault.current hold the paths of your vaults, vault.open the vault and file of the note that was open, vault.panes kept notes, and vault.outside vaults outside your home folder. They are harmless, but to forget them, close Herdr and delete those vault.* keys from shared.json.
