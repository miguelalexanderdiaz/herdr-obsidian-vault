Install

Both mods are needed. The panel opens notes in the reader, and the reader is opened by the panel. Install them under exactly the names vault and vault-reader.

Option 1: ask a Herdr agent

Herdr agents know how to install shared mods. Paste this into an agent running in Herdr, with the repository address filled in:

Install the Herdr mods from https://github.com/<owner>/herdr-obsidian-vault .
It has two mods, mods/vault and mods/vault-reader, and a keys.json.
Read every file first, tell me what they run and fetch, copy both
folders into my mods folder without overwriting anything, merge
keys.json after asking me about clashes, run herdr-app check on both
mods, then add the Vault panel to my layout.

The agent follows Herdr’s own rule: it reads everything and tells you before adding a mod that reaches the network or runs programs. This one does both, so expect that message. The list is on the privacy page.

Option 2: copy the folders yourself

  1. Get the repository: git clone https://github.com/<owner>/herdr-obsidian-vault.git (or download the zip).
  2. Find your Herdr home folder. It is ~/.config/herdr-app on macOS and Linux unless the variable HERDR_APP_HOME points elsewhere. herdr-app --help prints the path for your machine; use that on Windows.
  3. Copy mods/vault and mods/vault-reader into the mods folder inside that home. Do not overwrite a mod of the same name; if you already have one, rename the new folder and read the rename note. 
    # macOS and Linux
cp -R mods/vault mods/vault-reader ~/.config/herdr-app/mods/

# Windows PowerShell (replace the target with your Herdr home)
Copy-Item -Recurse mods\vault, mods\vault-reader "$HERDR_HOME\mods"
  4. Merge the keys from keys.json in the repository into your own keys.json (add the sections and keys; keep any key you already use). The keys are optional; see Configuration.
  5. Check both mods: 
    herdr-app check ~/.config/herdr-app/mods/vault
herdr-app check ~/.config/herdr-app/mods/vault-reader
    Both must pass. Herdr reloads mods as soon as their files change, so there is no restart.

Show the panel

The mods have "place": "none", so nothing appears until you put the panel somewhere. Pick one:

  • In a layout. Add a block to a column or stack of your layout file in layouts/: 
    { "id": "vault", "type": "block", "content": { "mod": "vault" } }
    For the herdr-portrait-layout layout, append that object to the children of the node whose id is panel-body. Its bar then shows a Vault button by itself.
  • Split a pane. Run the Herdr app command pane.split with a direction and mod set to vault (herdr-app commands lists its arguments).
  • As a popup. The repository’s keys.json binds Ctrl+Shift+E to mod.open:vault, which opens the panel as a 420 by 640 popup and, pressed again, closes it. Merge that key (see Configuration) and no layout change is needed.

First run

The panel starts with the vaults that Obsidian already lists on this machine, most recently opened first. If Obsidian has never been run, or the vault lives outside your home folder, use Add vault and pick a folder that contains .obsidian. To try the mod without a vault of your own, add examples/sample-vault from the repository.

Uninstall

  1. Remove the vault block from your layout and any keys you merged.
  2. Delete the folders mods/vault and mods/vault-reader from your Herdr home.
  3. Optional: delete data/vault in the Herdr home. It holds the picture cache, the Mermaid and MathJax copies, the headless browser profile and the reader settings. Nothing else is written outside the mod folders.

Your vaults are never touched. Herdr keeps the vault list in its own shared state (vault.list); it is harmless once the mods are gone.

For the author: publishing

These pages are served by GitHub Pages from the main branch and /docs folder. Turning that on, adding the herdr-mod topic and making the repository public are steps only the owner can take; they are listed in scripts/PUBLISH.md. Private repositories need a paid GitHub plan for Pages.
