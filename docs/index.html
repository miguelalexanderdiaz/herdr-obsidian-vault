Obsidian vault panel and reader for Herdr

Two small mods for the Herdr desktop app. One is a side panel that lists an Obsidian vault and searches it. The other is a floating reader that draws a note the way Obsidian shows it. Read-only: nothing ever writes into your vault.

What you get

  • Vault panel (mod vault), docked in a layout or as a popup on a key: a vault picker fed by Obsidian’s own vault list (with an Import from Obsidian item), a file tree, and full-text search with ripgrep.
  • Vault reader (mod vault-reader): front matter, callouts, wikilinks, embeds, images, tasks, tags, tables, math, Mermaid, Excalidraw drawings, Canvas files and PDFs.
  • A sample vault in examples/sample-vault that exercises every one of those.

Support level

macOS is the only OS the author uses; Linux and Windows code paths are implemented and covered by fake-platform unit tests but not run in the live app.

The code looks for every external program in the places that each operating system uses, and says in the panel which one is missing. The support table lists each feature per system. To report what you see on Linux or Windows, follow Check your install.

A CI workflow template is in the repository (scripts/ci.workflow.yml). It has not run yet because the author still has to install it, so no system is claimed to be checked by it.
