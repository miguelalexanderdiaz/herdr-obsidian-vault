Privacy and trust

Herdr mods are trusted code: they can run programs and reach the network. Here is everything these two do, so you can decide before installing. Nothing from your notes leaves your machine.

In short

  • It reads your vault and Obsidian’s vault list. It never writes into your vault.
  • It runs programs you installed (see the list below). It bundles none.
  • It uses the network for one thing: downloading a web image when a note shows one. You can turn that off.
  • It writes only under data/vault in the Herdr home.
  • No telemetry, no analytics, no accounts. This documentation site has no scripts, fonts or trackers from anywhere else.

Reads

WhatWhy
The folder of the selected vault, recursivelyThe tree, search, links, embeds, and live refresh (a folder watcher). Folders starting with a dot are skipped by the tree.
Obsidian’s vault list (obsidian.json, see the requirements)To start with the vaults you already have. Read once, on first run.
Obsidian’s obsidian.asarTo take out Mermaid and MathJax (only lib/mermaid.min.js and lib/mathjax) for the render script.

Herdr only lets mods read inside your home folder, so a vault elsewhere is not readable.

Dataview, Dataviewjs, Tasks and other plugin queries are never run; their text is displayed. Mermaid runs in its strict security mode.

Network

  • When a note shows an image with an http or https address, curl downloads it. The site that hosts the image sees your IP address and the request, as soon as the note is opened. Set remoteImages to false (Configuration) to stop this.
  • Links in a note are opened only when you click them, and only http, https and mailto addresses are passed to your system. file:, obsidian:, javascript: and every other scheme are ignored. Files that start programs are never opened from a note or from the tree.
  • The render page is local. The headless browser is not told to visit any other address.

Writes

Only under data/vault in the Herdr home: the cache (rendered pictures, copies of vault images, downloaded web images, page images of PDFs), lib (Obsidian’s Mermaid and MathJax), a temporary chrome-… profile folder per render run, and settings.json. Vault images are copied there because Herdr can only show pictures from its own folder. Cached pictures can contain a rendering of your private notes: delete data/vault/cache to wipe them. The cache is pruned by age and size automatically, once per session (see Configuration). A failed download or a missing program is never written to the cache.

Herdr keeps the vault list and the open note in its shared state, and the open folders of the tree in its per-mod storage.
