Usage

The Vault panel

  • Vault picker (top, with a small gem icon): shows the current vault. Click it for a menu of all vaults with a check mark on the current one. The x on a row removes the vault from this list only; the folder stays on disk. Add vault… opens the system folder picker and refuses a folder without .obsidian. Import from Obsidian reads Obsidian’s own list again and adds the vaults that are missing. A vault that Obsidian knows but that lies outside your home folder is shown dimmed with Outside your home folder: Herdr can’t read it.
  • Tree: folders first, then files, in natural order (note 2 before note 10). Names starting with a dot are hidden. Notes, canvases and drawings are shown without their extension, as Obsidian does. A folder with more than 2000 entries lists the first 2000 and ends with a line +N more not listed (search finds them). Open folders are remembered per vault. The tree refreshes by itself when files change on disk (on Linux, a very large tree is checked every 10 seconds instead, and the panel says so).
  • Click a file: notes, canvases, drawings, images and PDFs open in the reader. Anything else opens in the application your system uses for that file type, except files that start programs (.app, .exe, .bat, .sh, .ps1, .jar and similar): those are never launched from the panel and a notice says so.

Search

Type two letters or more in the box at the top. Results replace the tree after a 160 ms pause.

  • Every word you type must match, in any case. A note matches if the words are in its file name, or all in one line of its text.
  • Name matches come first, shorter names first, and show their first matching line when they have one. Then text matches, one line each.
  • At most 200 results. At most 20 matching lines are read per file (lines that contain the longest word you typed).
  • Searches .md and .canvas text. Excalidraw drawings match by name only, because their text is packed data. Hidden files and folders, and the folders .obsidian, .trash and .git, are skipped. Files that a .gitignore would hide are still searched.
  • Needs rg (ripgrep). Without it the panel says so and shows the install command for your system.
KeyDoes
Up DownMove through the results (wraps around).
EnterOpen the selected result.
EscClear the search and show the tree again.

The reader

A click in the panel opens a floating window that fills most of the screen (78% wide, 86% tall). The window has a bar with the vault icon, the note name, its folder, and buttons. It follows your Herdr theme.

KeyDoes
EscClose the floating reader.
Alt+Left or BackspaceGo back to the previous note (all systems).
Cmd+[Go back (macOS only).
  • Links. A wikilink or a markdown link to a note opens that note in the same reader, with a Back button (its tooltip names the keys that apply on your system). Links with a heading or block anchor ([[Note#Heading]], [[Note#^block]]) show only that section, with a button to show the whole note. A link to another kind of file opens it with the system, except files that start programs, which are never launched from a note (the reader says is a program: the reader doesn’t launch programs from notes). Only http, https and mailto addresses are opened; other schemes are ignored without a message.
  • Keep. The Keep menu pins the note into your Herdr space: New tab makes a tab named obsidian with this note, Add to obsidian splits one more pane below the notes of that tab. Kept panes follow edits to the file and are listed in the shared key vault.panes.
  • PDFs and images have a button in the bar to open the file outside the reader: Open in Preview on macOS, Open in the default app elsewhere.
  • Web images. When the open note shows pictures from the web, the bar has a Web images: on / off button. Switching it reloads the note. The choice is kept in data/vault/settings.json.
  • One line above the note says what could not be drawn and why (a missing program, a failed download). The note itself stays on screen with the source of each diagram or formula.
  • Live refresh. When the note, or a file it embeds, changes on disk, the reader draws it again.

What is drawn

ContentHow
Properties (front matter)Scalars, [a, b] lists and - item lists as a table; tags as chips. More complex YAML is shown as written.
MarkdownHeadings, emphasis, lists, quotes, code, tables and footnotes (by Herdr’s markdown view). ==highlight== is shown in bold, tags as code chips, tasks with custom marks ([/], [-], [>], [!]) with their own symbols. %%comments%% are hidden.
CalloutsThe 13 Obsidian kinds and their aliases, nested callouts, and + / - fold marks.
Links and embedsWikilinks with aliases, headings and block anchors; ![[note]] embeds up to two levels deep; images with |size; PDFs; drawings.
ImagesVault images at their pixel size, fitted to the window. Web images while the Web images button is on.
PDFsThe PDF you open shows up to 30 pages, one after another. A PDF inside a note or a canvas shows its first page. A click on a page opens the PDF outside the reader.
MathInline $…$ and block $$…$$ by MathJax.
MermaidDiagrams by Obsidian’s own Mermaid with a palette taken from your Herdr theme.
CanvasGroups, edges with labels and arrows, text cards, note and image cards, link cards. A wide canvas scrolls sideways.
Excalidraw.excalidraw.md and .excalidraw files, drawn clean by a small renderer of this project. It is not Excalidraw itself.
Dataview, Tasks, BasesThe query text is shown with a “shown, not run” label. Nothing is executed.

Not supported: editing (the reader is read-only), other Obsidian plugins, and file types not listed above (those open in the system application).

The sample vault note Feature tour contains one of each; open it to check an install.
