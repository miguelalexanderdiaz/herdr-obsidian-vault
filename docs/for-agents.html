For agents

If you are an AI agent asked to install, adapt or change these mods, start with AGENTS.md in the repository root. It covers the install checklist, what to tell the person first, the rules for editing a Herdr mod safely, the test commands and the rename procedure.

  • AGENTS.md: the full instructions.
  • llms.txt: a short map of this project for language models. A copy is served at llms.txt on this site.
  • llms-full.txt: the README, AGENTS.md and every page of this site as one plain text file, generated by scripts/build-llms-full.mjs. Read this if you cannot browse the site.
  • Check your install: the checklist on the sample vault and the report template, if you are asked to confirm a Linux or Windows install.
  • RECIPE.md: the brief to rebuild the mods from nothing (behaviour and intent only).
  • Privacy: the list of what to tell the person before adding the mods.

Say plainly what is not verified: Linux and Windows have not been seen running in the live Herdr app (see the support level on the requirements page), and the CI workflow is a template that has not run. AGENTS.md has the list and the Herdr facts behind each rule.

Three rules matter most. Never write inside a mod folder while it runs, because Herdr reloads a mod when any file in it changes. Never drive someone’s live Herdr window while testing; use herdr-app check on the mod folder and npm test. Keep personal data out of every file.
