Configuration

There is no settings screen. What can be changed is below, and everything that other mods or layouts may rely on is in the contract table.

Settings

SettingWhereDefaultDoes
remoteImagesdata/vault/settings.json in the Herdr home; the Web images: on/off button in the reader bar (shown when the note has web pictures)trueWhen false, notes that show a web image (![](https://…)) do not download it and the picture says Images from the web are turned off. Obsidian shows web images by default, so the default matches.
browserdata/vault/settings.json, edited by handnot setAbsolute path of the Chromium-family browser to use for diagrams, math and drawings. Tried before everything else. A relative path or a value that is not text is ignored without a message. Read again at every render run.
asardata/vault/settings.json, edited by handnot setAbsolute path of Obsidian’s obsidian.asar. Tried before everything else; the same rules as browser.

The order in which the browser and the obsidian.asar are looked for is on the requirements page.

Environment variables

VariableMeaning
HERDR_APP_HOMEChooses the Herdr home folder (Herdr’s own variable; the mods write under data/vault of whichever home is in use).
HERDR_VAULT_BROWSER, CHROME_PATHFull path of the browser program for the render script. Tried after the browser setting and before the usual install folders and the names on PATH.
HERDR_VAULT_ASARFull path of Obsidian’s obsidian.asar, tried after the asar setting and before the usual install folders.

The render script reads these, not the mod, so they only count if Herdr itself was started with them (a variable set in a shell profile does not reach a Herdr started from Finder or a launcher). The requirements page says how; the settings file above avoids the problem.

Keys

The repository ships a keys.json with one optional binding: Ctrl+Shift+M opens (and closes) the Vault panel as a popup. Merge it into your own keys.json; Herdr does not read it from the mod folder. If the key is already yours for something else, keep yours and open the panel with the app command mod.open from the command palette instead. The reader and search keys listed on the usage page are built in and cannot be remapped.

SectionKeyAction
globalctrl-shift-mmod.open:vault

Public contract

Other layouts and mods (the herdr-portrait-layout layout, for one) rely on these names. They do not change without a note on that project’s board. Do not rename them in a fork you want to stay compatible with. Today that layout reads the shared key vault.panes, treats a pane of the mod vault-reader as a note, and draws mods/vault/icons/book-open.svg; it does not read vault.list, vault.current or vault.open, which stay for other layouts.

vaultmodThe panel. Also draws its own picker menu when opened with the prop menu: true.
vault-readermodThe reader. Props: { vault, file, anchor?, kept?, id?, overlay? } where vault is an absolute folder and file a path inside it. The Keep menu uses { menu: true, window, vault, file, anchor, overlay }.
vault.listshared key[{ path, name }], the vaults shown in the picker.
vault.currentshared keyPath of the selected vault.
vault.openshared key{ vault, file, token } | null, the note the floating reader shows; the panel highlights it.
vault.panesshared key{ [pane id]: { vault, file, id } }, notes kept in panes, so a tree or pane header can show their names.
vault.outsideshared key[{ path, name }], vaults Obsidian knows that lie outside the home folder. Added in this release; it does not change the shape of vault.list.
vault.addmod commandSent to vault by its picker menu (and by a key that you bind) to open the add-vault folder picker.

What is stored

  • data/vault/cache in the Herdr home: pictures and their size files. Once per session, about 8 seconds after the first reader opens, entries older than 30 days are removed, then the oldest until the folder is under 200 MB. You can delete the folder at any time; it is rebuilt on demand.
  • data/vault/lib: Mermaid and MathJax copied from your Obsidian installation, once per Obsidian version.
  • data/vault/chrome-…: a private, temporary profile of the headless browser, one per run, removed when the run ends (leftovers older than an hour are swept).
  • data/vault/settings.json: the settings above.
  • Herdr shared state (shared.json): the keys of the contract table (vault.list, vault.current, vault.outside, vault.open, vault.panes), and one internal key, vault.adding. vault.adding is not part of the contract: it holds the time at which an Add vault folder picker was opened, so the docked panel and the popup copy do not open two pickers, and a picker abandoned for two minutes no longer blocks. Herdr’s per-mod storage: open:<vault path>, the open folders of the tree.
