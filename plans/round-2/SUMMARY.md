## What changed

**Code review** (log: `code-review-log.md`)
- Runtime truth: Herdr has no `TextDecoder`, `TextEncoder`, `structuredClone` or `Intl`, and `localeCompare` ignores its options. SVG images now decode without `TextDecoder`; the tree sorts with its own `naturalCompare`. Strict element and fs stubs generated from the real d.ts (`tests/stubs/gpui-methods.json`), a runtime-globals scan test and seeded-fault tests keep this class of bug visible.
- PDFs (embedded and canvas) go through Poppler; Quick Look is only the macOS fallback.
- Render page: CSP plus a loopback-only host-resolver rule and no-proxy flag. A zero-request canary test proves a Mermaid `<img>` label cannot reach the network.
- Search keeps CRLF text hits and normalises Windows `rg` paths.
- Browser and asar discovery: settings keys `browser` and `asar`, env vars, Linux candidates, login-shell lookup; Node gate 22.4 and `engines`.
- Own messages for notes/canvases over 1 MiB and vaults outside the home folder.
- End-to-end render test with a stub Obsidian bundle (skips with a stated reason when no browser).
- Cost and hygiene: bounded parallel fetches (4), no vault walk per folder event, panel row cap 3000, browser lifecycle module `render/browser.mjs` (polite close, group kill, profile removed last), cache touch-on-use, Quick Look and job-file cleanup, `)` in link targets, BOM before front matter, SPDX headers.
- Windows-safe tests (`pathToFileURL`, case-insensitive PATH clearing, `os.tmpdir`).
